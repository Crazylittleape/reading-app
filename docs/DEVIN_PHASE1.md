# 第一阶段：EPUB 导入、预览与上架

## 交付目标

让已登录管理员完成“上传文字版 EPUB → 预览元数据和全部分节 → 确认导入为草稿 → 上架 / 下架”，读者在现有 H5 中阅读已上架内容。

验收从干净克隆、空数据库和自建测试书开始，不依赖现有服务器、私人书籍、数据库备份或真实凭据。

## 分工与范围

- Devin 在独立分支实现、测试并交付 PR，不直接合并主分支或操作服务器。
- 审计方复查实际 diff、运行回归和浏览器验收；有问题退回修正。
- 发布方在测试环境验证后备份、部署并检查线上结果，保留上一版本及回滚说明。
- 开发会话不获取生产 `.env`、SSH 私钥、数据库或书籍内容；这些材料不提交仓库。

本阶段不做支付、会员套餐重构、AI 推荐、采集站、PDF OCR、原生安装包签名或整体框架迁移。TXT 导入可另开后续任务，不作为 EPUB 首版前置依赖。

## 功能要求

### 1. 受保护的上传入口

后台增加“导入 EPUB”。上传、预览、确认、查询和清理接口都必须校验管理员登录。写入操作使用 POST 和服务端 CSRF token；原 CMS 全局未开启 CSRF 时，新入口须自行实现。

首版接受不加密 EPUB，校验 ZIP、`META-INF/container.xml`、OPF manifest / spine 和实际资源。初始限制为上传 10 MiB、2000 个 ZIP 条目、全部解压内容 100 MiB、单条目 10 MiB；配置集中定义，并与 PHP / 网关体积限制一致。超过任一限制直接拒绝，不产生可发布书籍。

拒绝路径穿越、绝对路径、符号链接、重复规范化目标、远程资源下载和 XML 外部实体；不得按用户原文件名拼接服务器路径。检测到 DRM / 加密标记时明确提示不支持，不尝试解除保护。只校验后缀不能通过验收。

### 2. 解析与预览

- 从 OPF 获取书名、作者、语言和可选封面。作者可补填；缺少有效阅读顺序或正文时给出具体错误。
- 以 spine 为阅读顺序，结合 NCX、EPUB 3 navigation 和正文标题命名；粗目录不能导致小节丢失。
- 封面和原目录可单独处理，但图片专页、无标题页、前言和附录必须有明确去向，预览列出保留 / 排除范围。
- 显示元数据、封面、分节数、每节标题和可查看的内容；允许修改书名、作者、分类和分节标题。
- 保持文字顺序与段落。不得直接注入脚本、iframe、事件属性或不受信 HTML；预览和读者页面都应防止 XSS。
- 仅保留支持的本地栅格图并验证真实文件类型，使用服务端生成的相对资源路径，不依赖原 EPUB 临时路径和外部 URL。
- 无正文但有图的分节仍能预览；空文件或损坏内容应有可操作的失败提示。
- 预览不创建读者可见书籍。暂存内容归当前管理员所有，有过期时间与清理入口，其他账号不能猜 ID 读取或确认。

### 3. 幂等确认与可靠入库

确认前重新校验登录、CSRF、暂存归属和状态。确认请求带幂等标识；重复点击、网络重试或并发请求不能创建第二本书。

沿用 `mc_book` 与 `mc_book_chapter_{book_id % 100}`。`xid` 连续且顺序稳定；分配真实章节 ID 后，以目标环境 `APP_BOOK_KEY` 计算 `md5(str(chapter_id) + key).txt`。不得复用开发环境固定 ID、密钥和文件名。`text_num`、`nums`、分类及章节审核状态应匹配实际内容。默认导入免费草稿，确认成功不自动上架。

**事务前提必须真实成立。** 原始表使用 MyISAM；实现应让参与导入的书籍、章节和导入状态表具备事务能力，或提出可验证的替代原子方案。必要的 InnoDB 迁移仅覆盖相关表，PR 解释锁表、备份、兼容和回滚影响。不能把 MyISAM 包在 `BEGIN` 中就声称可回滚。

文件先写暂存区，验证后移动至最终目录。数据库回滚不会撤销文件，必须有失败补偿与中断恢复。数据库、正文或图片处理失败时，不留“目录存在但正文缺失”的可见书籍，不覆盖原有资源。

导入状态可查询。管理员看到处理中、成功或失败及简短原因；日志只含排障标识，不输出全书、密码和密钥。

### 4. 草稿与上架状态

复用现有 `yid` / `sid` 等字段语义，统一可见性。草稿和下架书不能通过读者列表、详情、目录或正文 API 读取，只隐藏列表不算完成。

上架前检查书名、作者、分类、至少一节有效内容及全部资源。上架后不重建 H5，刷新书库即出现；下架后新的 API 请求拒绝正文。已发送到设备的内容无法撤回，验收以新请求为准。

### 5. 阅读闭环

复用现有书库 → 详情 → 目录 → 正文 → 上下节 → 继续阅读链路。封面和插图处理与书名、书籍 ID、固定文件夹无关；只解析服务端生成的安全本地图片标记，不把任意正文作为外链。

正文用纯文本渲染，目录和错误消息也不得通过 `v-html` 注入不受信内容。图片页正常显示，字号和本机进度可恢复，不同书籍进度互不覆盖。错误重试针对失败的目标分节，空目录和网络异常提示明确。

## 测试样本

使用自己编写的短文本与生成图片，或明确允许再分发的材料。优先用代码生成 EPUB，不提交来历不明的电子书。

1. 粗粒度 NCX、多个 spine 小节的 EPUB 2。
2. EPUB 3 navigation、封面、插图、图片页和无标题页。
3. 中文、空格、`&`、引号和注释链接。
4. 缺失资源、损坏 ZIP、错误 MIME、加密标记和空正文。
5. 超限压缩包、路径穿越、XXE、脚本注入和外链资源。

## 可观察验收清单

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| A01 | 干净克隆初始化和启动 | 空书库可用，管理员可登录，不需要生产配置 |
| A02 | 未登录或 CSRF 错误时上传 / 确认 | 拒绝写入，不新增最终数据 |
| A03 | 导入合法 EPUB 2 / EPUB 3 | 元数据、spine 顺序和分节数正确 |
| A04 | 预览图片页、无标题页、前言及附录 | 去向明确，无静默丢失 |
| A05 | 修改元数据并确认 | 只创建一份草稿，数量与字数统计一致 |
| A06 | 重复或并发确认同一导入 | 返回原结果 / 状态，不重复建书 |
| A07 | 模拟 DB 或正文写入失败 | 状态可查，无残缺可见书籍，文件可补偿清理 |
| A08 | 请求草稿的列表 / 详情 / 目录 / 正文 | 全部不可供读者读取 |
| A09 | 上架后刷新 H5 | 无需重建，书籍出现且章节可读 |
| A10 | 图片页、字号、上下节与继续阅读 | 内容正确，进度属于当前书籍 |
| A11 | 下架后发起新的各类阅读请求 | 拒绝或统一返回不可用 |
| A12 | 上传攻击或超限样本 | 有界拒绝，无越界文件、外部下载或脚本执行 |
| A13 | 两本书并发导入 | ID、章节和资源不覆盖 |
| A14 | 检查、测试及 H5 构建 | 无真实凭据或书籍数据，锁文件一致，构建成功 |

成功样本按相同空白规范化规则逐节比较源文字与 API 输出，同时检查图片数、顺序和上下节 ID。页面能打开不能代替内容完整性验证。

## PR 与交付证据

建议按三个小 PR 交付：

1. **解析与安全预览**：样本、受保护入口、解析和元数据预览，包含拒绝路径测试；未确认内容不可公开。
2. **幂等确认与草稿入库**：结构迁移、真实事务策略、文件补偿、重试和并发测试。
3. **上架与阅读闭环**：状态操作、统一可见性、通用图片和 H5 浏览器验收。

每个 PR 说明问题、最终行为、迁移影响和实际验证命令，附相应测试结果和截图，列明未执行检查。不得提交临时 ZIP、数据库导出、真实凭据和私人日志。

发布前在独立测试卷从空环境复测 A01–A14。未经审计通过，不合并、不部署现有业务服务器。发布方负责备份数据库、正文、图片及匹配密钥，部署后检查真实页面、接口与容器健康，并保留上一版本恢复步骤。
